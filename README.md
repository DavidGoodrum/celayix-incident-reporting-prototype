# celayix-incident-reporting-prototype
Click-through prototype of incident reporting in Celayix Team Xpress, on the TEAMXP Design System. Based on the Claude
Design canvas "Incident reporting prototype — TEAMXP".

- `prototype-react` — Vite + React source (`npm install && npm run dev`).
- `prototype-html` — the same app as one self-contained `index.html`, generated from the React source
  (`npm run build:html`). Open it straight from disk.
